# fire-weather-southwestern-europe
Analysis and plotting code accompanying “Unprecedented fire weather in Southwestern Europe linked to spring drought and sea surface temperatures”.

The scripts cover FWI calculation, extreme event identification, composite and logistic regression analyses, and figure preparation using MPI-GE CMIP6 and ERA5 data. The code is currently being prepared for release and will be made publicly available upon acceptance of the manuscript.

Update the input and output paths before running the scripts. Raw climate datasets are not included; see the manuscript’s Data Availability statement for their sources. Scripts require preprocessed inputs, as specified in the code.
